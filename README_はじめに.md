# MealMate AI 日本料理・デザート認識 精度改善キット

## 現状（重要）
これは **追加学習を実行するためのキット** です。現時点では料理写真・学習済みモデルは同梱していません。従って **ゼリーの認識精度が上がったという実績はまだありません**。既存公開版を自動で更新するものでもありません。

## 1. 写真を集める
`data/train` と `data/test` に、同じ7つのカテゴリが用意されています。

| フォルダ名 | 日本語 | 初回の目標（学習/テスト） |
|---|---|---|
| jelly | ゼリー | 15 / 5 |
| pudding | プリン | 15 / 5 |
| yogurt | ヨーグルト | 15 / 5 |
| ramen | ラーメン | 15 / 5 |
| curry_rice | カレーライス | 15 / 5 |
| onigiri | おにぎり | 15 / 5 |
| other | その他（対象外食品など） | 15 / 5 |

- 画像形式は jpg/jpeg/png/webp/bmp。写真の著作権・利用条件を確認し、許諾のある画像や自分で撮影した写真を使ってください。
- **学習画像とテスト画像は完全に分ける**。同じ写真や連写、同じ製品のほぼ同一写真が双方に入ると精度が過大評価されます。
- 「その他」には分類対象外の異なる種類の食べ物を入れます。7分類だけでは未知の食品を確実に弾けません。
- 初回20枚/カテゴリは動作確認の最低限の目標です。精度改善には後から多様な実画像を増やす必要があります。

## 2. Windows・VS Code で学習
1. このフォルダをVS Codeで開く。
2. Python 3.10以上をインストールしていなければインストール。
3. `インストール.bat` をダブルクリック（インターネットが必要。PyTorchのダウンロード容量が大きいので注意）。
4. 写真を置いたら `学習スタート.bat` を実行。
5. 学習終了後、`results/report.json` に **テスト正答率**、`predictions.csv` に写真別結果、`confusion_matrix.csv` に誤認識の内訳が保存されます。

## 3. ブラウザでテスト
1. `model/japanese_food_model.onnx` と `model/labels.json` を `web/model/` にコピー。
2. VS Codeで `web/index.html` を開き、**Open with Live Server** を選択。
3. 写真を選び、「AIで判定する」を押す（ONNX RuntimeをCDNから読み込むためネット接続が必要）。
4. 1位の予測スコア65%未満か、1位と2位の差が20ポイント未満なら「不確か」と表示。**閾値は仮設定**であり、検証に基づいて見直す必要があります。

## 4. レポートに書く指標
- **正答率** = テスト画像で正しく分類した枚数 / 全テスト枚数 × 100
- 各料理ごとの正答率と混同行列で「ゼリー→ラーメン」を何件防げたか確認。
- **モデルの予測スコア（例 90%）は正答率とは異なる**。
- Food-101旧モデルと新モデルの比較は、同じテスト写真・同じ料理ラベルへの対応付けが必要。旧モデルでカテゴリ名が一致しない場合は単純比較しない。

## 5. 既存のMealMate AIへ反映するには
これは独立した精度検証キットです。既存Webアプリへ組み込むには、既存の画像認識処理を確認したうえで `web/app.js` の推論処理を組み込み、対応外の食品には手入力を残してください。**公開版はこのキットだけでは変更されません。**

## 注意事項
- カロリーはこの分類モデルでは推定しません。
- 食事写真の加工や著作権に注意してください。
- 画像は利用者の端末上で処理する構成ですが、外部CDNへの接続が生じます。
